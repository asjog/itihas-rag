१. दोन जाज्वल्य प्रतिनिधि,—भवानराव व भगवंतराव.
२. हैदरखानाची चढाई:—
( १ ) स. १७७४-७५ सालचें आक्रमण.
( २ ) गुत्तोचा पाडाव, मुरारराव घोरपड्याचा हृदयद्रावक अंत.
( ३ ) सावशीची लढाई, पटवर्धनांचा चक्काचूर, ( ९-१-१७७७ ).
( ४ ) परशुरामभाऊ व हरिपंत यांची लंगडी मोहीम.
३. करवीरकर छत्रपतींचा बारभाईंशीं विरोध:—
( १ ) पहिली अपुरी मोहीम.
( २ ) महादजीची मोहीम व तह.
( ३ ) छत्रपतींची फेरपलटाई.

इंग्रजांच्या युद्धाचें मुख्य अनुसंधान ठेवण्यांत इतर विषय बरेच राहून
गेले आहेत. राज्याचा पसारा देशभर चालूच होता. त्यांचें वर्णन विशिष्ट
कालखंड पाडून बरोबर साच्यांत बसविणें केव्हां केव्हां अशक्य होतें. अशा
कित्येक अवांतर विषयांची बोळवण या प्रकरणांत करावयाची आहे. पैकीं
उत्तर हिंदुस्थानांतले विषय तूर्त बाजूस ठेवून, दक्षिणेकडील घडामोडी तेवढ्या
येथें घेतों.
