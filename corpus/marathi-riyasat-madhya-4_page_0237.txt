बरोबर होते. रमाबाईसुद्धा मातुश्री गंगापुरास गेली. पुण्यास नारायणरावांजवळ मोरोबा फडणीस सर्व कारभार करितात. नाना फडणीस देखील कांहीं करणें तें मोरोबांस पुसून करितात. कृष्णराव बल्लाळ व महादाजीपंत गुरुजी नेहमीं दरबारांत असतात. श्रीमंतांबरोबर फारसे कोणी नाहींत. औषध घेत आहेत. कटोऱ्यास आषाढ शु० १, २६ जून ला सुवर्णतुला झाली. सप्तशृंगीचे स्वामी व कटोऱ्याचे स्वामी उभयतां अंगारा व तीर्थ देत असतात. उभयतां स्वामींची अट आहे कीं दादास मोकळिक करावी. हकीम, वैद्य वगैरे औषधें देतात. कटोऱ्यास कांहीं गुण वाटत आहे. ” ( जुलई स. १७७१ ).

२. निरवानिरव — प्रकृतीस बरें वाटूं लागल्यावरून माधवरावानें नारायणराव व इतर कारभारी यांस कटोरें येथें निकडीनें बोलावून घेतलें. तेथें नारायणरावास उपदेश केला त्याची नोंध ता. २८ ऑगस्ट स. १७७१ ची आहे ती अशी : ( १ ) बचाजीपंतावर कृपा करावी ; ( २ ) नाना फडणिसांशीं बहुत सख्य ठेवावें ; ( ३ ) रमावहिनीशीं सख्य असावें ; ( ४ ) पुण्यकर्म विशेष करावें ; ( ५ ) उदासीनता व क्रोध किंचित् कार्याकारण धरावा ; ( ६ ) इंद्रियनिग्रह करावा ; ( ७ ) पुस्तकांचा बंदोबस्त करावा ; ( ८ ) तीर्थरूपांची भेट झाल्यावर बोलून कृपा संपादन करावी ; ( ९ ) त्रिपदी पाठ करावी. नारायणरावाचा जन्म ता. १० ऑगस्ट स. १७५५ चा म्हणजे या उपदेशप्रसंगीं तो सोळा वर्षांचा होता. वरील प्रत्येक कलम सहेतुक स्पष्ट सांगितलें असल्यामुळें नारायणरावाचा स्वभाव पेशव्यास नापसंत पडून त्याजबद्दल भारी चिंता वाटत असली पाहिजे असें दिसतें. त्याच्या पुढील भवितव्याचें गमक या वरील नवविध आदेशांत थोडेंबहुत मिळतें.

ता. ८ ऑक्टोबर १७७१ ला पेशवा मातुश्रीस लिहितो, “ शरीर-संरक्षण विशेष करावें, बाबा वैद्यांस व सखारामपंतांस सत्वर समीप आणावें म्हणून आज्ञा, त्यास सखारामपंत मागेंच येऊन तीर्थरूपांकडे गेले. बाबा वैद्यही सत्वरच येतील. माझें पत्र दुसऱ्यास कळूं न देणें म्हणून आज्ञा, त्यास मर्जीप्रमाणें करतों. प्रस्तुत माझी प्रकृति बरीच आहे. उरांत दुखत होतें तें बरें झालें आहे. पोटांतही फिरंग्याचें औषध घेतों. ”*

* हा गोव्याचा पोर्तुगीज गृहस्थ नांव “ फ्रेड लियांद्र द माद्रिद द देऊस. ” ऐ. टि. २०१९ व ४-६.
