प्रकरण आठवें—गुजरातेतील मोहीम
 १ फत्तेसिंग गायकबाडाची फूट, गॉडर्डाशीं स्वतंत्र तह  २४०
 २ गॉडर्डकडे महादजीची तहाची हुलकावणी ... २४९
 ३ इंग्रजांशीं धाबपळीचें युद्ध ... ... २५४
 ४ गुजरात मोहिमेंतील फसगती ... ... २५८
 ५ नाना महादजींच्या उखळवेऱ्या ... ... २६६
प्रकरण नववें—अखिल हिंदुस्थानचा इंग्रजांवर उठाव
 १ कोंडाई बारीवरील छावणीचा वाद ... ... २७३
 २ इंग्रजांच्या शक्ती आंखडण्याचे उपाय ... ... २८३
 ३ हैदर नायकाचा इंग्रजांवर घसरा ... ... २९०
 ४ कृष्णाजी नारायणाची हैदराकडे बकिलात ... ... २९४
 ५ दुर्दैवी दादाची कहाणी ... ... ... ... २९७
 ६ कल्याण ब बसई इंग्रजांनीं जिंक्ली ... ... ३०१
 ७ बज्रजोगिणीचें सुदर्शन, रामचद्र गणेशाचा आत्मयज्ञ ... ३०६
प्रकरण दहावें—चौकडीच्या जुटीचा फलितार्थ
 १ बंगाल्यांतून इंग्रजांस उखडण्याचा नाना-महादजींचा प्रयत्न ३११
 २ चौकडीच्या कारस्थानांत भोसल्यांची गफलत ... ३१७
 ३ भोसल्यास फोडण्याची हेस्टिंग्सची कारवाई ... ४२५
 ४ दिवाकरपंत चोरघोडे ... ... ... ... ३३०
 ५ बोरघाटाखालीं इंग्रजांचा संहार, गॉडर्डाचें पलायन ... ३३१
 ६ माळव्यावर इंग्रजांची चढाई ... ... ... ... ३३७
 ७ स. १७८१ च्या बरसातची छावणी, महादजी ब म्यूर ३४३
प्रकरण अकरावें—युद्धसमारोप, सालबाईचा तह
 १ म्यूरमहादजींचा स्वतंत्र सलूख ... ... ... ३४३
 २ चेतसिंगाचा महादजीकडून पुरस्कार ... ... ३५८
 ३ तहाच्या पूर्वगामी बाटाघाटी ... ... ... ३५७
 ४ सालबाईच्या तहाचीं अव्वलअखेरचीं कलमें ... ३६२
 ५ सालबाई तहांतील नफानुकसानीची बिबिध चर्बां ... ३६५
